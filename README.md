# SG Tools (pyRevit)

A pyRevit extension of Revit tools for architectural and structural modelling, built as a learning project.

- **Ribbon tab:** SG Tools
- **Built for:** Revit 2027, pyRevit 6
- **Status:** setting up, no tools yet

Each tool here is rebuilt in C# in [sg-csharp-tools](https://github.com/sonusgeorge/sg-csharp-tools).
